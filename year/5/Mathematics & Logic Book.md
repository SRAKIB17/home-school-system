## ৩. ২ অঙ্কের যোগ ও বিয়োগ (Two-digit Math)

### যোগের নিয়ম (Addition)
* **পাশাপাশি যোগ:** ২১ + ১২ = ৩৩ / ৩৪ + ১৫ = ৪৯ / ৫০ + ২০ = ৭০।
* **ওপর-নিচ যোগ:**
  ```text
    ৩ ৪
  + ১ ২
  -----
    ৪ ৬
  ```
* **কথার অংক:** "আহমদের কাছে ১২টি বল ছিল। বাবা তাকে আরও ৫টি বল দিলে মোট কয়টি হলো?" (১২ + ৫ = ১৭)।

### বিয়োগের নিয়ম (Subtraction)
* **পাশাপাশি বিয়োগ:** ৪৫ - ২৩ = ২২ / ৫৮ - ১৪ = ৪৪ / ৬০ - ২০ = ৪০।
* **ওপর-নিচ বিয়োগ:**
  ```text
    ৭ ৫
  - ২ ৩
  -----
    ৫ ২
  ```
* **কথার অংক:** "গাছে ১৫টি পাখি ছিল। ৪টি উড়ে গেলে কয়টি রইল?" (১৫ - ৪ = ১১)।
