# সূচিপত্র (Year Pack — Age 2 / Level 0)

## 1) `2yrs_Arabic_Sensory.pdf` (৮–১২ পৃষ্ঠা)

* ভূমিকা: কীভাবে শেখাবেন (১ পৃষ্ঠা)
* ইউনিট ১–৮: **অক্ষর-সেন্সরি পেজ** (প্রতি পেজে ১টা বড় অক্ষর + ছবি + উচ্চারণ ক্লু)

  * উদাহরণ ইউনিট: ا (আলিফ) → “الله”, ب (বা) → “باب”, د (দাল) → “دار”
* রিভিউ পেজ ১–২: ছবিখোঁজা/ম্যাচিং
* প্যারেন্ট টিপস: ৫টি দ্রুত কৌশল

## 2) `2yrs_Quran_SingAlong.pdf` (৬ পৃষ্ঠা)

* পৃষ্ঠা 1–2: **সূরা আল-ফাতিহা** (লাইন-ভিত্তিক চ্যান্ট, সহজ রোমান, ১ লাইন বাংলা অর্থ)
* পৃষ্ঠা 3: **সূরা আল-ইখলাস** (ছবি-সহ)
* পৃষ্ঠা 4: **সূরা আল-ফালাক**
* পৃষ্ঠা 5: **সূরা আন-নাস**
* পৃষ্ঠা 6: **ছোট দু‘আ/যিকর** (Bismillah, Alhamdulillah, Subhanallah — “গান-ছন্দে”)

## 3) `2yrs_ABC_BangEn.pdf` (১২ পৃষ্ঠা)

* পৃষ্ঠা 1–2: **A–D (Anchor pages)** → **A = Allah** (ছবি/ইলাস্ট্রেশন), B, C, D
* পৃষ্ঠা 3–6: **E–L (Anchor pages)**
* পৃষ্ঠা 7–10: **রাইম/অ্যাকশন পেজ** (clap, point, trace—বড় ট্রেসলাইন)

> নোট: A–Z পুরো বছর জুড়ে কভার হবে (ফ্ল্যাশকার্ড + সাপ্তাহিক প্ল্যানে ছড়ানো আছে)।

## 4) `2yrs_Math_Playbook.pdf` (৮ পৃষ্ঠা)

# প্রতিটি লেসনের ফরম্যাট (Micro-Lesson Template, ৬–১২ মিনিট)

**শিরোনাম:** (যেমন: “A = Allah”, “Number 3”, “س (Seen) পরিচয়”)
**লক্ষ্য (১ লাইন):** শিশুটি অক্ষর/শব্দ/সংখ্যা চিনবে, ১টি কাজ করে দেখাবে
**সময়:** ৬–১২ মিনিট
**উপকরণ:** বড় ছবি/কার্ড, ১–২টা রিয়েল অবজেক্ট, স্টিকার

**ধাপগুলো:**

1. **Warm-up (১ মিনিট):** ছোট গান/সালাম (Bismillah)
2. **Show & Name (২–৩ মিনিট):** বড় কার্ড দেখান → নাম বলুন → শিশুকে পয়েন্ট করতে বলুন
3. **Sensory/Play (৩–৫ মিনিট):** ট্রেস/স্টিকার/ম্যাচ/ব্লক (হাত লাগিয়ে শিখুক)
4. **Manners/Du‘a (৩০–৬০ সেকেন্ড):** আজকের আচরণ/দু‘আ এক লাইন—একসাথে বলুন
5. **Wrap-up (১ মিনিট):** “দেখাও কোথায় A?”, “৩টা বল গুনে দাও”—১টা ছোট টাস্ক
6. **Mini-Check (টিকবক্স):** ✔ চিনল / ☐ কিউ দরকার / ☐ আজ না
   **হোম-হ্যাবিট (১ লাইন):** “আজ রাতে ১বার গানটা গাইবো”

## “১ সপ্তাহ”—নমুনা (Week 1)

* **Arabic:** ا (Alif) — “الله” শব্দের সাথে ছবি দেখানো
* **Quran:** Al-Fatiha (1–2) chant
* **English:** **A = Allah** (clap & point game)
* **Bangla:** “অ” + ছবি (অজগর/আম)
* **Math:** Number 1; Shape: Circle; Color: Red
* **Programming (Unplugged):** 2-step sequence (wash→eat)
* **Motor/Play:** Ball roll & catch (২ মিনিট টার্ন-টেকিং)
* **Manners:** Ask politely (দয়া করে)
* **Parent Tip:** Keep lessons under 10–12 minutes
