# Manners / Adab

## Age 2–3: Foundation Manners and Daily Habits

### 1) Daily routine and sequence
- 2-step sequence: wash hands → eat
- 3-step sequence: brush teeth → wash face → prayer time
- Dress up routine: shirt → pants → shoes
- Put toys in basket after play

### 2) Patterns and thinking skills
- Pattern ABAB using blocks
- Pattern AAB using cups or toys
- Find the missing item in a pattern
- Sort objects by big/small
- Sort by color or shape

### 3) Listening and following instructions
- Move left/right when told
- Sit quietly when asked
- Listen to one command and do it
- Repeat 3 claps
- Follow simple actions: jump, stop, clap, sit

### 4) Basic manners and character habits
- Say salam with smile
- Use polite words: please, thank you, sorry
- Wait for turn
- Share toys with others
- Keep hands and feet to self
- Eat without wasting food
- Keep room clean and tidy
- Help family members at home

### 5) Simple condition practice
- If clap → jump
- If teacher says “stop” → freeze
- If toy falls → pick it up
- If elder enters room → stand politely and greet

### 6) Problem-solving and attention
- Find the missing step in a routine
- Choose the correct action from two options
- Match the picture to the correct habit
- Tell what happens first and next

### 7) Gentle daily practice goals
- Practice 1 new manners habit each day
- Repeat the same lesson for 5–7 minutes
- Praise the child warmly after each good action
- Keep learning playful, short, and pressure-free

### 8) Sample weekly manners focus
- Day 1: Greeting and salam
- Day 2: Washing hands before eating
- Day 3: Saying thank you and please
- Day 4: Sharing toys
- Day 5: Waiting for turn
- Day 6: Cleaning up after play
- Day 7: Sitting politely and listening

### 9) Simple teacher note
This lesson helps children build good habits, respectful behavior, and basic listening skills through short playful activities and daily routine practice.
